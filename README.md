# Ecobed Insurance Brokers

Public website for Ecobed Insurance Brokers Ltd. (Economy Bedrock Insurance Brokers). The firm places personal and commercial cover from a head office in Ikeja, Lagos and an office in Garki, Abuja. Copy, offices, and leadership live in `lib/company.ts`.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, and Framer Motion.

## Pages

| Path | What it is |
| --- | --- |
| `/` | Home: who the brokerage is for, and how a placement moves from the risk to the policy |
| `/about` | The firm and its leadership |
| `/services` | Personal and commercial classes of business |
| `/contact` | Phone, email, offices, and the contact form |

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run build` then `npm start` runs the production server. `npm run lint` checks the project.
